# 検証記録

## 自動検証

`npm test` と `npm run build:extension` で確認します。API通信はモック、DOMはXのポスト構造を再現したフィクスチャを使用します。

検証する内容：本文のみの抽出、絵文字、引用の除外、表示枠の再利用、キーワードによる非表示と条件別解除、他スクリプトの非表示との共存、遅れたAI結果の無効化、接続先別の認証と形式、重複送信抑制、キャッシュの分離・削除、回答拒否と個別エラー後の継続、全体エラーの停止・待機、設定競合、キーの分離、入力中のキーを保存応答で失わないこと、削除確認。

設定プレビューは実際のダッシュボードと同じUIコードを使い、ブラウザで表示を確認します。プレビューの保存先はメモリ内です。

## 実機で確認する項目

Chromeへ `dist` を読み込み、以下を確認します。

1. Xのホーム・検索・ポスト詳細で、本文中の語が一致したポストが非表示になる。
2. スクロールで追加されたポストと、画面移動後のポストにも適用される。
3. 件数ツールチップから条件を一時解除・再適用できる。
4. 既存のメルカリ非表示スクリプトと併用しても、その非表示を取り消さない。
5. 各AIの接続許可とキーを設定し、実ポストで結果・速度・条件の妥当性を確認する。
6. AIをOFFにしてキーワード判定が継続する。
7. 拡張リロード後にXを再読み込みすると正常に再開する。

Xの実DOMと実APIでの確認は未実施です。引用の構造やポスト本文のDOMはXの更新で変わる可能性があります。
