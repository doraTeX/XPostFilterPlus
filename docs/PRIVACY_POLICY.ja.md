# XPostFilterPlus プライバシーポリシー

## 読み取る内容

Xのページで、表示されたポスト本文、表示枠の追跡に用いるポストID、投稿者のアカウント名を読み取ります。アカウント名は判定詳細のプロフィールリンクに使い、AIへの判定要求には追加しません。キーワード判定は端末内で行います。

## 外部への送信

AI判定を利用すると、ポスト本文と利用者が設定したAI判定条件を、選択した接続先へ送信します。本文に書かれている名前やURLなども本文の一部として送信されます。認証には、その接続先に登録したAPIキーまたはトークンを使います。

接続先はTypeSafe AI（Jev）、OpenAI（Decisions）、Cloudflare（Clef / Clef-flash）です。接続先の取り扱い・保存期間・料金は、それぞれの規約とプライバシーポリシーに従います。

開発者のサーバーや広告・解析サービスへの送信は行いません。

## 端末内への保存

キーワード、AI条件、接続設定、APIキー、直近10件の設定履歴、判定キャッシュをChromeのローカルストレージに保存します。「Chrome同期を有効にする」をオンにした場合は、キーワード・AI判定条件・表示設定を同じGoogleアカウントのChrome同期領域へ保存します。APIキー・キャッシュは同期しません。

APIキーはバックグラウンドと、ダイアログ内の拡張専用の設定フレーム（または単独のオプション画面）で扱い、Xページのスクリプトへ渡しません。設定JSONの書き出しと設定履歴にも含めません。キャッシュには本文・ポストIDを含む入力のハッシュと判定値を保存し、本文そのものは保存しません。

キャッシュは7日間・最大2,000件・約2MBを上限とします。個別エラーの再問い合わせを抑える記録は10分間有効です。有効期限を過ぎた記録は判定に使用せず、次のキャッシュ更新時に整理します。

Console継続出力のON/OFFは、Xタブごとに`chrome.storage.session`へ保存します。同じタブの再読み込みでは維持し、タブを閉じるかブラウザのセッションが終わると削除します。新しいタブではOFFです。Chrome同期・設定履歴・設定JSONには含めません。

判定詳細の表にはポスト本文、AIの判定対象本文、タブ内の処理ログ・表示変更ログが含まれ、Chromeの拡張セッションストレージに一時保存します。直近5件（合計6MBまで）は表の再読み込みに利用でき、古い表は新しい表を開くと整理します。ブラウザのセッション終了時にも削除されます。

## 権限について

| 権限 | 用途 |
| --- | --- |
| `storage` | キーワード・AI条件・表示設定・接続設定・認証情報・判定キャッシュ・設定履歴の保存。有効にした場合のみChrome同期で設定を同期します。認証情報・接続設定・キャッシュは同期しません。 |
| `alarms` | Chrome同期が有効な間の書き込み失敗の再試行と、設定の定期確認。サービスワーカーが停止していても、アラームから起動して処理を再開します。 |
| `https://x.com/*`、`https://twitter.com/*` | 表示中のポストを読み取り、非表示処理と件数チップ・設定操作を提供するため。 |
| `https://api.typesafe.ai/*`（任意） | 利用者が通信を許可した後、Jevへポスト本文・判定条件を送信し、判定結果を受け取るため。 |
| `https://api.openai.com/*`（任意） | 利用者が通信を許可した後、OpenAI Decisionsへポスト本文・判定条件を送信し、判定結果を受け取るため。 |
| `https://api.cloudflare.com/*`（任意） | 利用者が通信を許可した後、Cloudflare Clefへポスト本文・判定条件を送信し、判定結果を受け取るため。 |

実行するJavaScriptは拡張のパッケージに同梱しています。AIの応答はJSONデータとして処理し、コードとして実行しません。

## 削除

各接続先のAPIキーは設定画面の「APIキーを削除」で削除できます。「判定キャッシュを消去」でキャッシュを削除できます。拡張をアンインストールすると、拡張内に保存した設定とキーも削除されます。
