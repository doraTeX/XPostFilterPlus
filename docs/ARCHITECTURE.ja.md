# 実装構成

- `src/content/posts.ts`：ポスト本文を抽出。引用・カード・操作UIを除き、本文内の絵文字の代替テキストを保持します。
- `src/content/engine.js`：ポストIDと本文で表示枠の再利用を検出。非表示、条件別の一時解除、近傍ポストの判定キュー、設定反映を担当します。
- `src/background/controller.js`：接続先の選択、キーの保持、同時実行制御、同一入力の重複送信抑制、予算上限、キャッシュ、設定の競合検出を担当します。
- `src/background/index.ts`：Chrome APIと通信処理。設定操作は拡張自身のページに限定し、Xのコンテンツスクリプトには認証情報を返しません。
- `src/shared/ai.js` / `ai-errors.js`：接続先ごとのリクエスト・応答形式、エラー分類。
- `src/dashboard`：専用の設定タブ。自動保存、JSON移行、設定履歴、停止解除、キャッシュ削除を提供します。

非表示には専用の `data-xpf-hidden` 属性を付けます。一時解除や終了時にはこの属性だけを除去し、他の拡張・ユーザースクリプトが設定したインラインスタイルや目印を変更しません。

判定結果は条件・接続先・本文を含む識別子に結び付けます。設定変更やキャッシュ削除前に開始した応答は、変更後の結果として使用・保存しません。サービスワーカーが停止・再起動しても、保存済みのキャッシュと重大エラー状態を引き継ぎます。

ポスト単位の失敗は「非該当」として扱わず、結果が得られなかったものとして短時間記録します。接続先全体のエラーには待機または停止状態を保存し、並行処理の成功で重大エラーを取り消さないようにします。

- `src/content/overlay.ts`：Y!News Filter Plusと共通のチップ・条件タグ・進捗・回転矢印。タグDOMを保持してフォーカスを維持します。
- `src/shared/keyword-rules.js`：元の照合・行指定・除外率・重複整理を流用。
- `src/shared/sync.ts` / `src/background/sync-store.ts`：元のベクター時計・分割保存・競合解決を流用。
- `public/_locales/en` / `ja`：RakuFillと同じChrome標準i18n。未翻訳キーとプレースホルダーの不一致をビルド時に検出します。

設定画面は開いた元のXタブに自動対応します。キーワード・AI条件はすべてのXタブで共有し、使用量・一時表示・判定詳細は元のXタブに対応します。
