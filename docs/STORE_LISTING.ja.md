# XPostFilterPlus

XのポストをキーワードとAIで非表示にする非公式拡張です。X社とは無関係です。

キーワードを含むポストを非表示にするほか、Jev・OpenAI Decisions・Cloudflare Clefで、文章で指定した条件に合うポストを非表示にできます。条件は1行ずつ個別に判定し、いずれかが設定値以上なら非表示にします。AI判定は任意で、利用する接続先のAPIキーなどの登録と通信許可が必要です。Cloudflare Clefでは、モデルとしてclefまたはclef-flashを選べます。

おすすめ・フォロー中・リスト・検索などのタイムラインで動作します。「○件非表示中」にマウスを載せると条件を確認でき、クリックすると条件ごとに一時解除できます。設定画面は元のタイムラインに重ねて表示します。判定詳細では投稿者アカウントへのリンクも確認できます。設定の自動保存、任意のChrome同期、JSONバックアップ、保存履歴からの復元に対応しています。

対象は表示されているポスト自身の本文です。著者名・引用ポスト・リンクカードの文字は含めません。長文が省略されている場合は表示中の部分を判定し、展開すると再判定します。リンク先のページは取得しません。

キーワード判定は端末内で行います。AIを利用すると、本文と判定条件を選択した接続先へ送信し、料金・取り扱いはその接続先との契約に従います。APIキーは拡張のローカル領域に保存し、Chrome同期や設定JSONには含めません。開発者によるデータ収集サーバーはありません。

各AIの設定方法とプライバシーポリシーは、このリポジトリ内の案内を参照してください。
