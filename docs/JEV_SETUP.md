# Set up Jev

1. Sign in to the [TypeSafe AI console](https://console.typesafe.ai/keys) and create or copy an active API key.
2. Open X Post Filter Plus settings, expand **AI exclusion classification**, and turn on **Use AI classification**.
3. Under **AI provider**, select **Jev** and enter the key.
4. Select **Allow connections to this provider** and approve Chrome's request.
5. Enter one exclusion condition per line. Settings save automatically, and the key is checked with a minimal request.
6. Return to X. New and nearby posts are classified automatically.

An invalid key or missing connection permission turns the AI section pink and displays a cause and remedy. After fixing a provider-wide failure, select **Reclassify now**. Individual post errors or refusals do not stop other posts.

The extension sends post text and classification conditions to TypeSafe AI. Fees follow your agreement with the provider. API keys remain in local extension storage.
