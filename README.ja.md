# XPostFilterPlus

Xのポスト本文を、キーワードの一致とAIによる意味判定で非表示にする非公式のChrome拡張です。X社とは無関係です。バージョン0.1.0。

「Consoleに継続出力（デバッグ用）」はXページ上の設定画面だけに表示し、設定専用ページには表示しません。負荷が増すため通常はOFFで使用します。ONにすると同じXタブの再読み込みで維持し、タブを閉じると解除します。新しいタブではOFFです。Chrome同期・設定JSONには含めません。

## インストール

1. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このプロジェクトの **`dist` フォルダ**を選びます。
3. Xを開いている場合は、ページを再読み込みします。
4. ツールバーの拡張アイコンから、元のXページに重なる設定ダイアログを開きます。

設定専用ページには「設定を開く」「Xを開く」を表示します。設定ダイアログを閉じても入口ページは残り、再び開けます。

ZIPで受け取った場合は、展開したフォルダを読み込んでください。

## 使い方

「除外キーワード」に、語を1行に1つずつ入力します。設定は自動保存され、開いているXのページに反映されます。全角・半角、英字の大文字・小文字、アクセント、中黒などの表記ゆれを吸収できます。

意味で非表示にする場合は「AI判定を利用」をオンにし、「非表示にする条件」を1行に1つずつ入力します。例：`他人を嘲笑・罵倒するポスト`、`攻撃的口調のポスト`。

接続先は次の順に選べます。

| 接続先 | 入力するもの | 設定ガイド |
| --- | --- | --- |
| Jev | APIキー | [Jev](docs/JEV_SETUP.ja.md) |
| OpenAI Decisions | OpenAI APIキー | [OpenAI Decisions](docs/OPENAI_DECISIONS_SETUP.ja.md) |
| Cloudflare Clef / Clef-flash | APIトークン・アカウントID・モデル | [Cloudflare Clef](docs/CLOUDFLARE_SETUP.ja.md) |

入力後に「この接続先への通信を許可」を押し、Chromeで許可します。APIの利用料金は利用者と各接続先との契約に従います。

Xのページ右上の「○件非表示中」をクリックすると、元のタイムラインに重ねて設定ダイアログが開きます。拡張がまだ動作していないXタブでは、設定を別タブで開き、元ページの再読み込みを案内します。マウスを載せると、非表示になった条件が表示されます。条件をクリックすると、その条件を一時解除します。ホバー時にチップ左上へ現れる赤い一時停止ボタンで、そのXタブの除外をまとめて一時解除できます。緑の再生ボタンを押すと再開します。設定画面の「一時的に全件表示」と同じ状態で連動します。一時解除はページの再読み込み・画面移動でリセットされます。「閉じる」と入力欄外でのEscは、保存完了を待ってダイアログだけを閉じます。入力欄にフォーカスがある間は、Escを押しても閉じません。保存に失敗した場合は入力内容を残します。判定詳細の2列目には、投稿者のアカウントへのリンクを表示します。元ページURLの下にある1行の検索欄で、ポスト本文全体の部分一致検索と判定種別を組み合わせて行を絞り込めます。各タグの件数は、チェックがOFFの種別も含めて検索後のヒット件数に更新します。英字の大文字・小文字は区別せず、入力を消すと判定種別に応じた表示に戻ります。

## 判定と保存

- 対象は画面内とその前後にあるポストの本文です。引用ポスト、著者名、リンクカード、ボタンの文字を本文から除きます。本文が表示されていないポストは判定しません。省略された長文は表示中の部分だけを判定し、「さらに表示」で展開すると再判定します。
- キーワードに一致したポストはAIへ送信せずに非表示にします。AI判定では、いずれかの条件が設定値以上になったポストを非表示にします。
- 追加読み込みと画面移動を監視し、同じ表示枠が別ポストに再利用された場合は本文を確認し直します。AIの結果が届くまでポストが表示されることがあります。
- キャッシュは7日間・最大2,000件・約2MBを上限とし、接続先・モデル・本文・実際に送る指示文（言語を含む）ごとに分けます。個別の判定失敗は10分間再問い合わせを抑えます。
- 回答拒否、応答の不備、ポスト単位の送信エラー・タイムアウトはそのポストをスキップします。キー無効、権限不足、残高不足などはAI判定を一時停止し、設定画面に対処方法を表示します。キーワードによる非表示は継続します。
- 設定とAPIキーはこのChromeプロファイルの端末内に保存します。Chrome同期をオンにするとキーワードと判定条件を同じGoogleアカウントのChrome間で同期し、競合は内容を比較して選択できます。設定JSONの書き出しと直近10件の設定履歴からの復元に対応しています。APIキーはJSON・設定履歴に含めません。同期が有効な間は`alarms`権限で5分ごとに再確認し、通信失敗時にも再試行します。

除外率はポストごとの結果を記憶するため、スクロールで表示枠が入れ替わっても同じポストの表示を保ちます。一時解除した語は飛ばし、次に一致するキーワードを適用します。設定画面の定期更新では件数・統計のみを取得し、判定詳細は操作したときに取得します。

AIは誤判定する場合があります。条件や判定値を調整し、必要に応じて一時解除してください。

## 開発

[English guide](README.md)。英語・日本語をChromeのUI言語に合わせて表示します。両言語のリソースと置換指定を `npm run check:i18n` で検査します。

```sh
npm ci
npm test
npm run build:extension
npm run package
```

`dist` が読み込み用、`release/xpost-filter-plus-0.1.0.zip` が配布用です。`npm run build` は `.build-check` に検証用ビルドを作成します。

```sh
npm run preview
```

`http://127.0.0.1:4178/preview/index.html` でAPI通信を伴わない設定画面のプレビューを開けます。`npm run icons` はmacOSのSwift/AppKitでアイコンを生成します。
